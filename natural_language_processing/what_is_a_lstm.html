What is a LSTM?

A Long Short-Term Memory cell upgrades the plain RNN with a protected memory conveyor and three gates that decide what to forget, what to store, and what to reveal. Step through a sentence and watch the gates work.

Input Sequence

Forget-Gate Bias

-3 · forget fast 0.0 +3 · remember long

A positive bias pushes the forget gate toward 1, so the cell state survives more steps — this is exactly why LSTMs are initialised with a high forget bias in practice. Changing it resets the run.

LSTM: Memory with a Bouncer at the Door

How three gates and a protected cell state let a network remember for hundreds of steps.

The Problem LSTMs Solve

A plain recurrent cell rewrites its entire memory at every step — hₜ = tanh(…) squashes and mixes everything, so information from 30 words ago gets multiplied down to nothing (the vanishing gradient you saw in the previous module). The Long Short-Term Memory cell (Hochreiter & Schmidhuber, 1997) fixes this by splitting memory in two: a protected cell state Cₜ that flows along a conveyor with only tiny, gated edits, and a hidden state hₜ used as the working output.

Three Gates, Three Decisions

Each gate is a small sigmoid layer producing values between 0 (closed) and 1 (open), one per memory dimension:

  • Forget gate fₜ — looks at the new token and the previous output and decides which parts of the old cell state to erase. Reading “however” might wipe the sentiment stored so far.
  • Input gate iₜ — decides which parts of the new candidate information to write into the cell state.
  • Output gate oₜ — decides how much of the cell state to reveal as this step's output hₜ. Memory can stay private: stored but not shown until it is needed.

Why the Conveyor Beats the Vanishing Gradient

The crucial line is Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙C̃ₜ. The old memory is multiplied by the forget gate and added to — never squashed through a tanh and never forced through the recurrent weight matrix. When the forget gate sits near 1, gradients flow backwards along this additive path almost undamped, like an express lane through time. That is the whole trick: addition preserves, repeated multiplication destroys.

Interactive Exploration Guide

  1. Auto-run the default sentence and watch the three gate bars dance — each token opens and closes the gates differently.
  2. Compare the two memory rows. The cell state (amber) drifts smoothly — gated edits — while the hidden state (green) can jump, because the output gate re-decides what to reveal at every step.
  3. Drag the forget bias to +3 and re-run: the forget bar pins near 1 and the cell state values pile up and persist — long memory. Now drag it to -3: the forget bar collapses toward 0 and the cell state gets wiped every step — the LSTM degrades into a memoryless network.

Key Takeaway

An LSTM is a recurrent cell where memory updates are decisions, not defaults: forget what is stale, store what matters, reveal what is needed. The additive cell-state conveyor is what lets gradients — and therefore memories — survive across long sequences. Its lighter cousin, the GRU, achieves nearly the same with two gates — that is the next module.

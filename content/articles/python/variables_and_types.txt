title: Variables and Types: A Practical Guide
intro: A name is not a box. It is a label that points at a value.

## The idea in brief

When you write <code class="mono-font">age = 36</code>, Python creates the value <code class="mono-font">36</code> and points the name <code class="mono-font">age</code> at it. The value lives on its own; the name is just a label. Assign again and the label moves — the old value is left behind, and once nothing references it, it is cleaned up.

## Why types matter

The type of a value decides what the operators mean. <code class="mono-font">+</code> on two <code class="mono-font">int</code>s adds them; <code class="mono-font">+</code> on two <code class="mono-font">str</code>s concatenates them. Neither is "wrong" — the behaviour follows the type. When a program does something surprising, nine times out of ten a value is a different type than you assumed, and <code class="mono-font">type()</code> settles it in one line.

## Guided tour

1. <strong>Read the outputs.</strong> In the first editor, check the order: the two values print, then their two types. The last line runs only after the first three have finished.
2. <strong>Reuse a name.</strong> Add <code class="mono-font">age = "six"</code> as a new last line and run. The label <code class="mono-font">age</code> now points at a string — same name, new value, new type.
3. <strong>Compare the arithmetic.</strong> The second editor prints <code class="mono-font">"10"+"10" = "1010"</code> but <code class="mono-font">10+10 = 20</code>. That is the whole lesson in two lines.
4. <strong>Break the glue.</strong> Try <code class="mono-font">print(a + b)</code> in the second editor and run. Python's error message is a type complaint: you cannot add a string and an int, and it tells you exactly which types collided.

## The short of it

A variable is a label, not a container. The type of the value it labels is chosen by Python, and it dictates behaviour — especially what <code class="mono-font">+</code> means. Whenever behaviour looks wrong, ask <code class="mono-font">type()</code> first; it is the single most useful question you can ask a running program.

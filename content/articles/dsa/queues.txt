title: Queues (FIFO)
intro: Fair ordering by construction &mdash; and the one change that turns DFS into BFS.

## Context first


A <strong>queue</strong> serves items in the order they arrived: <strong>FIFO</strong>, First In, First Out. You add at the back (<em>enqueue</em>) and remove from the front (<em>dequeue</em>). It is the queue at a shop, modelled exactly.

Queues appear wherever work needs to be processed in the order it was submitted. A web server queues incoming requests.

## Why the Naive Implementation Is Wrong

If you implement a queue as a plain array and dequeue by removing element 0, every dequeue shifts all remaining elements down one position &mdash; that is <strong>O(n)</strong>, not O(1).

Real implementations avoid this. A linked list with head and tail pointers gives O(1) at both ends. Or you keep the array and move <em>pointers</em> instead of data, which leads directly to the circular queue.

## The Insight That Matters Most

Choose <strong>Stack vs queue traversal</strong> and step through. Both run identical code over the same graph. The only difference is where pending nodes are taken from:

- Take from the <strong>end</strong> (stack, LIFO) &rarr; you dive deep down one branch first. That is <strong>depth-first search</strong>.
- Take from the <strong>front</strong> (queue, FIFO) &rarr; you sweep level by level. That is <strong>breadth-first search</strong>.

One data-structure choice completely changes the traversal order &mdash; and with it, whether the algorithm finds the shortest path. BFS does; DFS does not.

## Variants Worth Knowing

- <strong>Deque</strong> (double-ended queue) &mdash; add and remove at both ends. Can act as either a stack or a queue.
- <strong>Priority queue</strong> &mdash; serves the <em>highest priority</em> item rather than the oldest. Usually built on a heap, and the engine behind Dijkstra and A*.
- <strong>Blocking queue</strong> &mdash; waits when empty or full. The standard tool for passing work between threads.

## First in, first out

A queue adds at one end and removes from the other. The oldest item is served first, which is what "queue" means outside computing too.

|Operation|Meaning|Cost|
|---|---|---|
|enqueue|Add to the back|O(1)|
|dequeue|Remove from the front|O(1)|
|peek|Look at the front|O(1)|
|is_empty|Nothing left|O(1)|

In Python, use `collections.deque` and not a list:

```python
from collections import deque

q = deque()
q.append(1)          # enqueue at the back
q.append(2)
q.popleft()          # 1 - dequeue from the front, O(1)
```

<strong>A list is the wrong choice.</strong> `list.pop(0)` shifts every remaining element, so it is O(n), and a loop dequeuing n items becomes O(n²). This is the single most common queue performance bug, and it is easy to miss because the code looks correct and works on small inputs.

`deque` is implemented as a doubly linked list of fixed-size blocks, giving O(1) at both ends with far better cache behaviour than one node per element.

## Why BFS needs a queue

The clearest use, and the reason it appears in every graph algorithm discussion.

Breadth-first search must process all nodes at distance 1 before any at distance 2. A queue's first-in-first-out order produces exactly that: neighbours added later are processed later, so exploration proceeds in rings.

```python
def bfs(graph, start):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        for nbr in graph[node]:
            if nbr not in visited:
                visited.add(nbr)
                q.append(nbr)
    return visited
```

Swap `popleft()` for `pop()` and the same code becomes depth-first search. The data structure <em>is</em> the algorithm's traversal order &mdash; which is the neatest illustration of why choosing the right structure matters.

## Experiments to try

1. <strong>Enqueue A, B, C then dequeue.</strong> A comes out first &mdash; the opposite of a stack.
2. <strong>Switch to circular mode.</strong> Dequeue a few, enqueue a few more, and watch the indices wrap around to reuse slots instead of shifting data.

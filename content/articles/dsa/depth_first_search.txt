title: Depth-First Search
intro: Depth-first search (DFS) follows one path as far as it can, then backtracks to the nearest unexplored choice. A stack—explicit or supplied by recursion—keeps track of where to return.

## Follow a path, then backtrack

Mark the start visited. Choose an unvisited neighbour and continue; when the current node has no unvisited neighbours, return to the previous node. The order depends on the graph’s neighbour ordering, but every reachable node is visited once when a visited set is used.

Choose **Structure Type** in the visualizer, then press **Start Search** and **Step** to see one path grow and retreat. **Auto** completes the traversal; **Reset State** starts again. A different neighbour order can produce a different valid DFS order.

## A graph implementation

```python
def dfs(graph, start):
    seen = set()
    order = []

    def visit(node):
        seen.add(node)
        order.append(node)
        for neighbour in graph[node]:
            if neighbour not in seen:
                visit(neighbour)

    visit(start)
    return order
```

The recursive calls form an implicit stack. A node is marked when first reached, which prevents a cycle from repeating the traversal.

## What DFS is useful for

DFS can explore connected components, detect cycles, produce a topological order in a directed acyclic graph, and support maze or state-space search. It does not guarantee the shortest path. For shortest paths by edge count in an unweighted graph, use breadth-first search.

With an adjacency-list graph, DFS takes <code>O(V + E)</code> time and <code>O(V)</code> extra space for visited nodes and the call stack. Recursive DFS is concise, but a very deep graph can exceed the language’s call-stack limit; an explicit stack avoids that recursion limit.

## Common mistakes

- **Skipping the visited set:** cycles can send the search around forever.
- **Marking only after exploring neighbours:** a node may be pushed repeatedly; mark it when discovered.
- **Assuming one fixed traversal order:** it depends on the order in which neighbours are listed.
- **Using DFS for shortest paths:** depth-first order does not minimize distance.

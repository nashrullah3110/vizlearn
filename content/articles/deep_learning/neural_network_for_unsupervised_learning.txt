title: Neural Network for Unsupervised Learning: A Practical Guide
intro: With no labels to learn from, you make the input its own target. Squeeze it through a narrow layer and the network has to work out what was worth keeping.

## The autoencoder trick

An autoencoder is trained to reproduce its own input. On its own that is trivial. Copy the input to the output and the loss is zero. The trick is the bottleneck: a hidden layer narrower than the input. It the data must pass through.

Since the bottleneck cannot carry all, the network is forced to decide what matters. What survives the squeeze is a learned, compressed form. And it is learned without a single label. The encoder maps the input down to the bottleneck. The decoder maps the bottleneck back up to the first dimension. The loss is the rebuild error (often MSE). And backpropagation trains both halves jointly. After training, the encoder alone is useful: it gives a low-dim form of any input that gets the structure the decoder needed to reconstruct it. This is dim count reduction, like PCA. But nonlinear &mdash; the hidden layers can learn curved manifolds that a linear way would miss. Variants include denoising autoencoders (corrupt the input, reconstruct the clean version, which forces the bottleneck to learn noise-resistant features), variational autoencoders (VAEs, which learn a chance spread over the latent space and can generate new samples). And sparse autoencoders (which penalise output to learn a wider but mostly-inactive bottleneck). This page trains a small autoencoder on 8-dim data, prints the rebuild error. And shows how the 3-dim bottleneck gets the dominant correlations.

## A worked shape

8 input features &rarr; 3-unit bottleneck &rarr; 8 reconstruction outputs. The encoder must express 8 counts with 3. And the decoder must rebuild all 8 from those 3.

If those 8 features are genuinely free, the reconstruction will be poor. There is nothing to compress. If a few are linked, as real features often are, the network finds those links and reconstruction gets surprisingly close. The loss is simply <span class="mono-font">MSE(input, reconstruction)</span>.

## Learning without labels

Supervised learning needs a target for each case. Most data has none. And labelling it is the costly part of each project.

Unsupervised ways learn structure from the data it. For neural networks the dominant trick is to <strong>invent a target from the input</strong>. So that ordinary supervised machinery can be used on unlabelled data. That reframing is called self-supervision. And it is what made modern language and vision pretraining possible.

The main families:

|Approach|Invented target|Used for|
|---|---|---|
|Autoencoder|Reconstruct the input|Compression, denoising, anomaly detection|
|Masked prediction|Predict hidden parts|BERT, MAE &mdash; pretraining|
|Next-token prediction|Predict what follows|Language models|
|Contrastive|Are these two views the same item?|SimCLR, CLIP &mdash; representation learning|
|Generative (VAE, GAN, diffusion)|Produce plausible samples|Image and audio generation|

## Autoencoders, and why the bottleneck matters

An autoencoder is two networks back to back. The <strong>encoder</strong> compresses the input into a small vec. The <strong>decoder</strong> reconstructs the input from it. The loss is rebuild error. How far the output is from the input.

<p class="mono-font">x &rarr; encoder &rarr; z (small) &rarr; decoder &rarr; x&#770;&nbsp;&nbsp;&nbsp;&nbsp;loss = &#8214;x&#770. &minus; x&#8214;&sup2;</p>

The bottleneck is the whole design. Force 784 pixels through a 32-dim vec and the network cannot memorise. It must find the structure that lets it rebuild the input from 32 counts. Those 32 counts are a learned compression of the data.

Remove the bottleneck &mdash; make `z` as large as the input. And the network learns the identity function. It teaches it nothing. Constraint is what creates the form.

Three real uses:

<strong>Anomaly detection.</strong> Train on normal data just. Anything that reconstructs badly is unlike what the net has seen. And rebuild error turns an anomaly score. This is one of the most widely deployed unsupervised tricks in industry.

<strong>Denoising.</strong> Feed a corrupted input and ask for the clean first. The network cannot copy its input. So it must learn what the data ought to look like.

<strong>Dim count reduction.</strong> A non-linear option to PCA. With linear outputs and squared error, an autoencoder recovers the PCA subspace just. So it is a strict transfer.

## Contrastive learning, and why it dominates

The idea: take two tweaked views of the same pic. And train the network to give close embeddings for them and dissimilar embeddings for views of <em>other</em> pics.

No labels are needed &mdash; the supervision comes fully from knowing which pairs came from the same source. What the network learns is what is invariant under the augmentations you chose: crop it, recolour it, flip it. And it is still the same object.

That last point is the crux. <strong>The augmentations set what the form considers key.</strong> Include colour jitter and the net learns colour-invariant features. It is right for object recognition and wrong for distinguishing ripe from unripe fruit.

Contrastive pretraining on unlabelled data followed by fine-tuning on a small labelled set routinely beats training from scratch on the labelled set alone. And in specialised domains it beats ImageNet setup too. CLIP extends the idea across modalities, matching pics with their captions. It is what gives it zero-shot sorting.

## Try this above

1. Set <strong>Input Features</strong> to 8 and squeeze the hidden layer to 2. A hard compression &mdash; just the strongest structure survives.
2. Widen the hidden layer until it matches the input width. Reconstruction turns near-perfect and fully uninformative: the network has learned to copy.
3. Check that <strong>Reconstruction Output</strong> always matches <strong>Input Features</strong>. It must &mdash; the output is being compared against the input.

## What often goes wrong

<strong>A bottleneck as wide as the input.</strong> The network learns the identity function, the loss looks excellent. And you have learned nothing about the data. If reconstruction is perfect, suspect this first.<strong>Reading reconstruction loss as quality.</strong> Low loss just means the input was reproducible. It says nothing about whether the compressed form is useful for anything else. Judge it by how well the bottleneck features do on a downstream task.

## In one line

No labels needed &mdash; make the input the target and let a narrow layer decide what was worth keeping.

## Variational autoencoders and generative nets

A plain autoencoder's latent space has gaps: pick a random point in it and the decoder gives nonsense, since nothing constrained the space to be continuous.

A <strong>variational autoencoder</strong> fixes that by having the encoder output a spread rather than a point. And adding a KL divergence term that pulls those spreads towards a standard normal. The latent space turns smooth and samplable. So you can generate new cases by drawing a random point and decoding it.

The trade is sharpness: VAE samples tend to be blurry, since the reconstruction loss rewards the average of plausible outputs.

<strong>GANs</strong> take a other route. A generator and a discriminator trained against each other. Giving sharper samples at the cost of unstable training and mode collapse. <strong>Diffusion nets</strong> learn to reverse a gradual noising process. And now dominate pic generation on quality and stability alike.

All three are unsupervised in the same sense: the training signal comes from the data, not from labels.

## Clustering, and where networks fit

Classical clustering &mdash; k-means, DBSCAN, hierarchical. Operates on the raw features and struggles on high-dim unstructured data, since distances there are not meaningful.

The standard modern pipeline is two stages: <strong>learn a form</strong> with a self-supervised network, then <strong>cluster in that embedding space</strong> with an ordinary algorithm. Pics that look alike land near each other in the embedding. So k-means on embeddings finds groups that k-means on pixels never could.

Deep clustering ways (DEC and successors) train the form and the clustering jointly. It can work better and is much more fiddly.

## Four ways to train with no labels at all

Reconstruction, clustering, self-prediction and density -- four objectives that need no target column, run on the same data so you can see what each one really tunes.

```python-run
import numpy as np

rng = np.random.default_rng(0)

# three blobs in 10 dimensions. the labels exist only so we can CHECK the
# results afterwards -- none of the four methods below ever sees them.
K, DIM, N = 3, 10, 500
centres = rng.normal(size=(K, DIM)) * 1.15
labels = rng.integers(0, K, N).astype(np.int32)   # int32: WASM numpy
                                                 # bincount will not take int64
X = centres[labels] + rng.normal(0, 1.5, (N, DIM))   # heavy overlap
X = (X - X.mean(0)) / X.std(0)
print("%d rows, %d dimensions, %d hidden groups that overlap heavily."
      % (N, DIM, K))
print("the group labels are used ONLY to score the results at the end.")
print()

def purity(assign):
    # what fraction of rows share the majority true label of their group
    total = 0
    for g in np.unique(assign):
        m = assign == g
        if m.any():
            total += np.bincount(labels[m], minlength=K).max()
    return total / len(labels)

print("baseline: assigning everything to one group scores %.4f purity,"
      % purity(np.zeros(N, dtype=int)))
print("because the largest true group is that fraction of the data.")
print()
```

```python-run
import numpy as np

print("1. RECONSTRUCTION -- an autoencoder. the target is the input itself.")
def autoencoder(k, epochs=800, lr=0.03):
    r = np.random.default_rng(1)
    P = [r.normal(0, 0.4, (DIM, 16)), np.zeros((1, 16)),
         r.normal(0, 0.4, (16, k)),   np.zeros((1, k)),
         r.normal(0, 0.4, (k, 16)),   np.zeros((1, 16)),
         r.normal(0, 0.4, (16, DIM)), np.zeros((1, DIM))]
    m = [np.zeros_like(p) for p in P]
    v = [np.zeros_like(p) for p in P]
    for t in range(1, epochs + 1):
        a1 = np.tanh(X @ P[0] + P[1])
        code = a1 @ P[2] + P[3]
        a2 = np.tanh(code @ P[4] + P[5])
        out = a2 @ P[6] + P[7]
        d = 2 * (out - X) / N
        g6, g7 = a2.T @ d, d.sum(0, keepdims=True)
        d2 = (d @ P[6].T) * (1 - a2 ** 2)
        g4, g5 = code.T @ d2, d2.sum(0, keepdims=True)
        dc = d2 @ P[4].T
        g2, g3 = a1.T @ dc, dc.sum(0, keepdims=True)
        d1 = (dc @ P[2].T) * (1 - a1 ** 2)
        g0, g1 = X.T @ d1, d1.sum(0, keepdims=True)
        for i, g in enumerate((g0, g1, g2, g3, g4, g5, g6, g7)):
            m[i] = 0.9 * m[i] + 0.1 * g
            v[i] = 0.999 * v[i] + 0.001 * g ** 2
            P[i] -= lr * (m[i] / (1 - 0.9 ** t)) / (np.sqrt(v[i] / (1 - 0.999 ** t)) + 1e-8)
    a1 = np.tanh(X @ P[0] + P[1])
    code = a1 @ P[2] + P[3]
    out = np.tanh(code @ P[4] + P[5]) @ P[6] + P[7]
    return code, ((out - X) ** 2).mean()
```

The next block covers the left steps.

```python-run
import numpy as np

code, rec = autoencoder(2)
print("   2-unit code, reconstruction MSE %.4f (predicting the mean scores %.4f)"
      % (rec, ((X - X.mean(0)) ** 2).mean()))
print("   the objective is 'reproduce the input', so the code keeps whatever")
print("   is needed for that -- which is variance, not necessarily groups.")
print()

def kmeans(Z, k, iters=60, seed=0):
    r = np.random.default_rng(seed)
    C = Z[r.choice(len(Z), k, replace=False)]
    for _ in range(iters):
        d = ((Z[:, None, :] - C[None]) ** 2).sum(2)
        a = d.argmin(1)
        for c in range(k):
            if (a == c).any():
                C[c] = Z[a == c].mean(0)
    return a, ((Z - C[a]) ** 2).sum()

print("2. CLUSTERING -- k-means. the objective is compactness, nothing else.")
a_raw, inertia = kmeans(X, K)
print("   on the raw 10-D data : purity %.4f, inertia %.1f" % (purity(a_raw), inertia))
a_code, _ = kmeans(code, K)
print("   on the 2-D code above: purity %.4f" % purity(a_code))
print("   the autoencoder was not trying to help k-means, and here it")
print("   %s. compression and clustering are different objectives that"
      % ("did" if purity(a_code) > purity(a_raw) else "did not"))
print("   sometimes agree.")
print()
```

```python-run
import numpy as np

print("3. SELF-PREDICTION -- hide part of the input, predict it from the rest.")
print("   this is what a language model does, and it needs no labels either:")
HOLD = 3
def masked_fit(epochs=800, lr=0.03):
    r = np.random.default_rng(2)
    P = [r.normal(0, 0.4, (DIM - HOLD, 24)), np.zeros((1, 24)),
         r.normal(0, 0.4, (24, HOLD)), np.zeros((1, HOLD))]
    m = [np.zeros_like(p) for p in P]
    v = [np.zeros_like(p) for p in P]
    seen, hidden = X[:, :-HOLD], X[:, -HOLD:]
    for t in range(1, epochs + 1):
        h = np.tanh(seen @ P[0] + P[1])
        out = h @ P[2] + P[3]
        d = 2 * (out - hidden) / N
        g2, g3 = h.T @ d, d.sum(0, keepdims=True)
        dh = (d @ P[2].T) * (1 - h ** 2)
        g0, g1 = seen.T @ dh, dh.sum(0, keepdims=True)
        for i, g in enumerate((g0, g1, g2, g3)):
            m[i] = 0.9 * m[i] + 0.1 * g
            v[i] = 0.999 * v[i] + 0.001 * g ** 2
            P[i] -= lr * (m[i] / (1 - 0.9 ** t)) / (np.sqrt(v[i] / (1 - 0.999 ** t)) + 1e-8)
    h = np.tanh(seen @ P[0] + P[1])
    return h, ((h @ P[2] + P[3] - hidden) ** 2).mean()

hid, mse = masked_fit()
print("   predict the last %d columns from the first %d: MSE %.4f"
      % (HOLD, DIM - HOLD, mse))
print("   guessing the mean would score %.4f" % (X[:, -HOLD:] ** 2).mean())
a_self, _ = kmeans(hid, K)
print("   clustering its hidden layer: purity %.4f" % purity(a_self))
print("   the target was manufactured from the data itself. that is the")
print("   whole trick behind every self-supervised method.")
print()
```

```python-run
import numpy as np

print("4. DENSITY -- fit a gaussian and score how unusual each row is.")
mu, cov = X.mean(0), np.cov(X.T) + 1e-6 * np.eye(DIM)
inv = np.linalg.inv(cov)
d2 = np.einsum("ij,jk,ik->i", X - mu, inv, X - mu)
print("   Mahalanobis distance: median %.2f, 99th percentile %.2f"
      % (np.median(d2), np.percentile(d2, 99)))
odd = np.argsort(-d2)[:5]
print("   the 5 most unusual rows are at distances %s"
      % np.round(d2[odd], 1))
print("   no labels, no clusters -- just 'how surprising is this row'. this")
print("   is the objective behind anomaly detection, and it answers a")
print("   different question from the other three.")
print()

print("%-34s %12s" % ("method", "purity"))
for name, a in (("k-means on raw data", a_raw),
                ("k-means on autoencoder code", a_code),
                ("k-means on self-prediction features", a_self)):
    print("%-34s %12.4f" % (name, purity(a)))
print("%-34s %12.4f" % ("everything in one group", purity(np.zeros(N, dtype=int))))
print()
print("the lesson is not which number is largest. it is that all four")
print("objectives are legitimate and none of them is 'unsupervised learning'")
print("in general -- each optimises a specific thing:")
print("   reconstruction  -> keep enough to rebuild the input")
print("   clustering      -> put nearby points in the same group")
print("   self-prediction -> keep enough to predict the missing part")
print("   density         -> know what normal looks like")
print()
print("choosing among them is choosing what you want, and there is no label")
print("column to tell you afterwards whether you chose correctly. that is")
print("the genuinely hard part of unsupervised work, and it is a design")
print("question rather than a modelling one.")
```

## Questions people ask

<strong>Is self-supervised learning the same as unsupervised?</strong> Self-supervision is a subset: it invents labels from the data. The training loop is then fully supervised.

<strong>How small should an autoencoder's bottleneck be?</strong> Small enough to force compression. Treat it as a hyperparameter. And watch reconstruction quality against the downstream task.

<strong>Are autoencoders good for anomaly detection?</strong> Yes. And with a caveat: train on normal data just. And be aware that a sufficiently flexible autoencoder can learn to reconstruct anomalies too.

<strong>Should I use PCA or an autoencoder?</strong> PCA first. It is faster, deterministic and readable. An autoencoder wins when the structure is genuinely non-linear and there is enough data.

<strong>Do I still need labels?</strong> For the final task, often a few. The point of pretraining is that a small labelled set turns enough.

<strong>Which self-supervised way should I use?</strong> For pics, a contrastive or masked-pic way. For text, masked or next-token prediction. Or start from a published pretrained net rather than doing it yourself.

## Recap in one screen

- Unsupervised networks invent a target from the input. So supervised machinery can learn from unlabelled data.
- Autoencoders rebuild their input through a bottleneck. The constraint is what forces a useful form.
- Rebuild error is a real anomaly score. And denoising autoencoders learn what clean data looks like.
- Contrastive learning trains views of the same item to embed together. And your augmentations decide what the form ignores.
- VAEs, GANs and diffusion nets generate. Pretrain then fine-tune is the standard way to exploit unlabelled data.

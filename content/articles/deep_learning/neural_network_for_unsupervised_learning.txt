title: Neural Network for Unsupervised Learning: A Practical Guide
intro: With no labels to learn from, you make the input its own target. Squeeze it through a narrow layer and the network has to work out what was worth keeping.

## The autoencoder trick

An autoencoder is trained to reproduce its own input. On its own that is trivial &mdash; copy the input to the output and the loss is zero. The trick is the bottleneck: a hidden layer narrower than the input, which the data must pass through.

Because the bottleneck cannot carry everything, the network is forced to decide what matters. What survives the squeeze is a learned, compressed representation, and it is learned without a single label.

## A worked shape

8 input features &rarr; 3-unit bottleneck &rarr; 8 reconstruction outputs. The encoder must express 8 numbers using 3, and the decoder must rebuild all 8 from those 3.

If those 8 features are genuinely independent, the reconstruction will be poor &mdash; there is nothing to compress. If several are correlated, as real features usually are, the network finds those relationships and reconstruction gets surprisingly close. The loss is simply <span class="mono-font">MSE(input, reconstruction)</span>.

## Learning without labels

Supervised learning needs a target for every example. Most data has none &mdash; and labelling it is the expensive part of every project.

Unsupervised methods learn structure from the data itself. For neural networks the dominant trick is to <strong>invent a target from the input</strong>, so that ordinary supervised machinery can be used on unlabelled data. That reframing is called self-supervision, and it is what made modern language and vision pretraining possible.

The main families:

|Approach|Invented target|Used for|
|---|---|---|
|Autoencoder|Reconstruct the input|Compression, denoising, anomaly detection|
|Masked prediction|Predict hidden parts|BERT, MAE &mdash; pretraining|
|Next-token prediction|Predict what follows|Language models|
|Contrastive|Are these two views the same item?|SimCLR, CLIP &mdash; representation learning|
|Generative (VAE, GAN, diffusion)|Produce plausible samples|Image and audio generation|

## Autoencoders, and why the bottleneck matters

An autoencoder is two networks back to back. The <strong>encoder</strong> compresses the input into a small vector; the <strong>decoder</strong> reconstructs the input from it. The loss is reconstruction error &mdash; how different the output is from the input.

<p class="mono-font">x &rarr; encoder &rarr; z (small) &rarr; decoder &rarr; x&#770;&nbsp;&nbsp;&nbsp;&nbsp;loss = &#8214;x&#770; &minus; x&#8214;&sup2;</p>

The bottleneck is the whole design. Force 784 pixels through a 32-dimensional vector and the network cannot memorise; it must find the structure that lets it rebuild the input from 32 numbers. Those 32 numbers are a learned compression of the data.

Remove the bottleneck &mdash; make `z` as large as the input &mdash; and the network learns the identity function, which teaches it nothing. Constraint is what creates the representation.

Three practical uses:

<strong>Anomaly detection.</strong> Train on normal data only. Anything that reconstructs badly is unlike what the model has seen, and reconstruction error becomes an anomaly score. This is one of the most widely deployed unsupervised techniques in industry.

<strong>Denoising.</strong> Feed a corrupted input and ask for the clean original. The network cannot copy its input, so it must learn what the data should look like.

<strong>Dimensionality reduction.</strong> A non-linear alternative to PCA. With linear activations and squared error, an autoencoder recovers the PCA subspace exactly &mdash; so it is a strict generalisation.

## Contrastive learning, and why it dominates

The idea: take two augmented views of the same image, and train the network to produce similar embeddings for them and dissimilar embeddings for views of <em>different</em> images.

No labels are needed &mdash; the supervision comes entirely from knowing which pairs came from the same source. What the network learns is what is invariant under the augmentations you chose: crop it, recolour it, flip it, and it is still the same object.

That last point is the crux. <strong>The augmentations define what the representation considers important.</strong> Include colour jitter and the model learns colour-invariant features, which is right for object recognition and wrong for distinguishing ripe from unripe fruit.

Contrastive pretraining on unlabelled data followed by fine-tuning on a small labelled set routinely beats training from scratch on the labelled set alone, and in specialised domains it beats ImageNet initialisation too. CLIP extends the idea across modalities, matching images with their captions, which is what gives it zero-shot classification.

## Try this above

1. Set <strong>Input Features</strong> to 8 and squeeze the hidden layer to 2. A hard compression &mdash; only the strongest structure survives.
2. Widen the hidden layer until it matches the input width. Reconstruction becomes near-perfect and completely uninformative: the network has learned to copy.
3. Check that <strong>Reconstruction Output</strong> always matches <strong>Input Features</strong>. It must &mdash; the output is being compared against the input.

## What usually goes wrong

<strong>A bottleneck as wide as the input.</strong> The network learns the identity function, the loss looks excellent, and you have learned nothing about the data. If reconstruction is perfect, suspect this first.<strong>Reading reconstruction loss as quality.</strong> Low loss only means the input was reproducible, which says nothing about whether the compressed representation is useful for anything else. Judge it by how well the bottleneck features perform on a downstream task.

## In one line

No labels needed &mdash; make the input the target and let a narrow layer decide what was worth keeping.

## Variational autoencoders and generative models

A plain autoencoder's latent space has gaps: pick a random point in it and the decoder produces nonsense, because nothing constrained the space to be continuous.

A <strong>variational autoencoder</strong> fixes that by having the encoder output a distribution rather than a point, and adding a KL divergence term that pulls those distributions towards a standard normal. The latent space becomes smooth and samplable, so you can generate new examples by drawing a random point and decoding it.

The trade is sharpness: VAE samples tend to be blurry, because the reconstruction loss rewards the average of plausible outputs.

<strong>GANs</strong> take a different route &mdash; a generator and a discriminator trained against each other &mdash; producing sharper samples at the cost of unstable training and mode collapse. <strong>Diffusion models</strong> learn to reverse a gradual noising process, and now dominate image generation on quality and stability alike.

All three are unsupervised in the same sense: the training signal comes from the data, not from labels.

## Clustering, and where networks fit

Classical clustering &mdash; k-means, DBSCAN, hierarchical &mdash; operates on the raw features and struggles on high-dimensional unstructured data, because distances there are not meaningful.

The standard modern pipeline is two stages: <strong>learn a representation</strong> with a self-supervised network, then <strong>cluster in that embedding space</strong> with an ordinary algorithm. Images that look alike land near each other in the embedding, so k-means on embeddings finds groups that k-means on pixels never could.

Deep clustering methods (DEC and successors) train the representation and the clustering jointly, which can work better and is considerably more fiddly.

## Four ways to train with no labels at all

Reconstruction, clustering, self-prediction and density -- four objectives that need no target column, run on the same data so you can see what each one actually optimises.

```python-run
import numpy as np

rng = np.random.default_rng(0)

# three blobs in 10 dimensions. the labels exist only so we can CHECK the
# results afterwards -- none of the four methods below ever sees them.
K, DIM, N = 3, 10, 500
centres = rng.normal(size=(K, DIM)) * 1.15
labels = rng.integers(0, K, N).astype(np.int32)   # int32: WASM numpy
                                                 # bincount will not take int64
X = centres[labels] + rng.normal(0, 1.5, (N, DIM))   # heavy overlap
X = (X - X.mean(0)) / X.std(0)
print("%d rows, %d dimensions, %d hidden groups that overlap heavily."
      % (N, DIM, K))
print("the group labels are used ONLY to score the results at the end.")
print()

def purity(assign):
    # what fraction of rows share the majority true label of their group
    total = 0
    for g in np.unique(assign):
        m = assign == g
        if m.any():
            total += np.bincount(labels[m], minlength=K).max()
    return total / len(labels)

print("baseline: assigning everything to one group scores %.4f purity,"
      % purity(np.zeros(N, dtype=int)))
print("because the largest true group is that fraction of the data.")
print()

print("1. RECONSTRUCTION -- an autoencoder. the target is the input itself.")
def autoencoder(k, epochs=800, lr=0.03):
    r = np.random.default_rng(1)
    P = [r.normal(0, 0.4, (DIM, 16)), np.zeros((1, 16)),
         r.normal(0, 0.4, (16, k)),   np.zeros((1, k)),
         r.normal(0, 0.4, (k, 16)),   np.zeros((1, 16)),
         r.normal(0, 0.4, (16, DIM)), np.zeros((1, DIM))]
    m = [np.zeros_like(p) for p in P]
    v = [np.zeros_like(p) for p in P]
    for t in range(1, epochs + 1):
        a1 = np.tanh(X @ P[0] + P[1])
        code = a1 @ P[2] + P[3]
        a2 = np.tanh(code @ P[4] + P[5])
        out = a2 @ P[6] + P[7]
        d = 2 * (out - X) / N
        g6, g7 = a2.T @ d, d.sum(0, keepdims=True)
        d2 = (d @ P[6].T) * (1 - a2 ** 2)
        g4, g5 = code.T @ d2, d2.sum(0, keepdims=True)
        dc = d2 @ P[4].T
        g2, g3 = a1.T @ dc, dc.sum(0, keepdims=True)
        d1 = (dc @ P[2].T) * (1 - a1 ** 2)
        g0, g1 = X.T @ d1, d1.sum(0, keepdims=True)
        for i, g in enumerate((g0, g1, g2, g3, g4, g5, g6, g7)):
            m[i] = 0.9 * m[i] + 0.1 * g
            v[i] = 0.999 * v[i] + 0.001 * g ** 2
            P[i] -= lr * (m[i] / (1 - 0.9 ** t)) / (np.sqrt(v[i] / (1 - 0.999 ** t)) + 1e-8)
    a1 = np.tanh(X @ P[0] + P[1])
    code = a1 @ P[2] + P[3]
    out = np.tanh(code @ P[4] + P[5]) @ P[6] + P[7]
    return code, ((out - X) ** 2).mean()

code, rec = autoencoder(2)
print("   2-unit code, reconstruction MSE %.4f (predicting the mean scores %.4f)"
      % (rec, ((X - X.mean(0)) ** 2).mean()))
print("   the objective is 'reproduce the input', so the code keeps whatever")
print("   is needed for that -- which is variance, not necessarily groups.")
print()

def kmeans(Z, k, iters=60, seed=0):
    r = np.random.default_rng(seed)
    C = Z[r.choice(len(Z), k, replace=False)]
    for _ in range(iters):
        d = ((Z[:, None, :] - C[None]) ** 2).sum(2)
        a = d.argmin(1)
        for c in range(k):
            if (a == c).any():
                C[c] = Z[a == c].mean(0)
    return a, ((Z - C[a]) ** 2).sum()

print("2. CLUSTERING -- k-means. the objective is compactness, nothing else.")
a_raw, inertia = kmeans(X, K)
print("   on the raw 10-D data : purity %.4f, inertia %.1f" % (purity(a_raw), inertia))
a_code, _ = kmeans(code, K)
print("   on the 2-D code above: purity %.4f" % purity(a_code))
print("   the autoencoder was not trying to help k-means, and here it")
print("   %s. compression and clustering are different objectives that"
      % ("did" if purity(a_code) > purity(a_raw) else "did not"))
print("   sometimes agree.")
print()

print("3. SELF-PREDICTION -- hide part of the input, predict it from the rest.")
print("   this is what a language model does, and it needs no labels either:")
HOLD = 3
def masked_fit(epochs=800, lr=0.03):
    r = np.random.default_rng(2)
    P = [r.normal(0, 0.4, (DIM - HOLD, 24)), np.zeros((1, 24)),
         r.normal(0, 0.4, (24, HOLD)), np.zeros((1, HOLD))]
    m = [np.zeros_like(p) for p in P]
    v = [np.zeros_like(p) for p in P]
    seen, hidden = X[:, :-HOLD], X[:, -HOLD:]
    for t in range(1, epochs + 1):
        h = np.tanh(seen @ P[0] + P[1])
        out = h @ P[2] + P[3]
        d = 2 * (out - hidden) / N
        g2, g3 = h.T @ d, d.sum(0, keepdims=True)
        dh = (d @ P[2].T) * (1 - h ** 2)
        g0, g1 = seen.T @ dh, dh.sum(0, keepdims=True)
        for i, g in enumerate((g0, g1, g2, g3)):
            m[i] = 0.9 * m[i] + 0.1 * g
            v[i] = 0.999 * v[i] + 0.001 * g ** 2
            P[i] -= lr * (m[i] / (1 - 0.9 ** t)) / (np.sqrt(v[i] / (1 - 0.999 ** t)) + 1e-8)
    h = np.tanh(seen @ P[0] + P[1])
    return h, ((h @ P[2] + P[3] - hidden) ** 2).mean()

hid, mse = masked_fit()
print("   predict the last %d columns from the first %d: MSE %.4f"
      % (HOLD, DIM - HOLD, mse))
print("   guessing the mean would score %.4f" % (X[:, -HOLD:] ** 2).mean())
a_self, _ = kmeans(hid, K)
print("   clustering its hidden layer: purity %.4f" % purity(a_self))
print("   the target was manufactured from the data itself. that is the")
print("   whole trick behind every self-supervised method.")
print()

print("4. DENSITY -- fit a gaussian and score how unusual each row is.")
mu, cov = X.mean(0), np.cov(X.T) + 1e-6 * np.eye(DIM)
inv = np.linalg.inv(cov)
d2 = np.einsum("ij,jk,ik->i", X - mu, inv, X - mu)
print("   Mahalanobis distance: median %.2f, 99th percentile %.2f"
      % (np.median(d2), np.percentile(d2, 99)))
odd = np.argsort(-d2)[:5]
print("   the 5 most unusual rows are at distances %s"
      % np.round(d2[odd], 1))
print("   no labels, no clusters -- just 'how surprising is this row'. this")
print("   is the objective behind anomaly detection, and it answers a")
print("   different question from the other three.")
print()

print("%-34s %12s" % ("method", "purity"))
for name, a in (("k-means on raw data", a_raw),
                ("k-means on autoencoder code", a_code),
                ("k-means on self-prediction features", a_self)):
    print("%-34s %12.4f" % (name, purity(a)))
print("%-34s %12.4f" % ("everything in one group", purity(np.zeros(N, dtype=int))))
print()
print("the lesson is not which number is largest. it is that all four")
print("objectives are legitimate and none of them is 'unsupervised learning'")
print("in general -- each optimises a specific thing:")
print("   reconstruction  -> keep enough to rebuild the input")
print("   clustering      -> put nearby points in the same group")
print("   self-prediction -> keep enough to predict the missing part")
print("   density         -> know what normal looks like")
print()
print("choosing among them is choosing what you want, and there is no label")
print("column to tell you afterwards whether you chose correctly. that is")
print("the genuinely hard part of unsupervised work, and it is a design")
print("question rather than a modelling one.")
```

## Questions people ask

<strong>Is self-supervised learning the same as unsupervised?</strong> Self-supervision is a subset: it invents labels from the data. The training loop is then fully supervised.

<strong>How small should an autoencoder's bottleneck be?</strong> Small enough to force compression. Treat it as a hyperparameter, and watch reconstruction quality against the downstream task.

<strong>Are autoencoders good for anomaly detection?</strong> Yes, and with a caveat: train on normal data only, and be aware that a sufficiently flexible autoencoder can learn to reconstruct anomalies too.

<strong>Should I use PCA or an autoencoder?</strong> PCA first &mdash; it is faster, deterministic and interpretable. An autoencoder wins when the structure is genuinely non-linear and there is enough data.

<strong>Do I still need labels?</strong> For the final task, usually a few. The point of pretraining is that a small labelled set becomes sufficient.

<strong>Which self-supervised method should I use?</strong> For images, a contrastive or masked-image approach; for text, masked or next-token prediction. Or start from a published pretrained model rather than doing it yourself.

## Recap in one screen

- Unsupervised networks invent a target from the input, so supervised machinery can learn from unlabelled data.
- Autoencoders reconstruct their input through a bottleneck; the constraint is what forces a useful representation.
- Reconstruction error is a practical anomaly score, and denoising autoencoders learn what clean data looks like.
- Contrastive learning trains views of the same item to embed together &mdash; and your augmentations decide what the representation ignores.
- VAEs, GANs and diffusion models generate; pretrain then fine-tune is the standard way to exploit unlabelled data.

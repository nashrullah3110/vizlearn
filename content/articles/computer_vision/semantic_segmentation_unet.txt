title: Semantic Segmentation and U-Net: A Practical Guide
intro: Classification asks what's in the image. Segmentation asks, for every single pixel.

## The idea in brief

Semantic segmentation labels every pixel with a class, not just the image as a whole. A CNN classifier's usual move — <a href="downsampling_in_cnn.html" style="color: var(--accent-primary)">pool down repeatedly</a> to build up wide receptive fields and semantic context — is exactly what a segmentation decoder then has to undo, pixel by pixel, to produce a full-resolution output mask.

## What pooling actually destroys

Max or majority pooling is a real, lossy operation: a 2&times;2 block of pixels becomes one pixel, and whatever varied within that block is gone for good. Naively upsampling the coarse result back up — nearest-neighbour or bilinear, with nothing else — cannot recover that lost detail, because the information needed to recover it no longer exists anywhere in the coarse map. <strong>U-Net's skip connections</strong> route the encoder's full-resolution feature maps directly across to the matching decoder stage, so the fine spatial detail pooling destroyed never has to be reconstructed from nothing — it's simply still there, carried across.

## Labelling every pixel

Classification gives one label per image. Detection gives a box per object. <strong>Semantic segmentation</strong> gives a label to every single pixel &mdash; road, building, sky, person &mdash; producing an output the same size as the input.

Three related tasks are easy to confuse:

|Task|Output|Distinguishes individual objects?|
|---|---|---|
|Semantic segmentation|A class per pixel|No &mdash; all cars are "car"|
|Instance segmentation|A mask per object|Yes|
|Panoptic segmentation|Both, combined|Yes, plus background classes|

The architectural difficulty is a genuine tension. Recognising <em>what</em> something is needs a wide view and abstract features, which means downsampling. Knowing <em>exactly which pixels</em> it occupies needs full resolution, which downsampling destroys.

## U-Net's answer: go down, come back up, and remember

U-Net is shaped like a U, and the shape is the idea.

<strong>The encoder</strong> (the left side) is a standard convolutional stack: convolutions and downsampling, halving the resolution and doubling the channels at each stage. By the bottom it has a rich, abstract, low-resolution representation &mdash; it knows what is in the image.

<strong>The decoder</strong> (the right side) upsamples back to full resolution, halving the channels at each stage.

<strong>The skip connections</strong> are what make it work. At each level, the encoder's feature map is concatenated onto the decoder's, so the decoder has both the semantic information from the deep path and the fine spatial detail from the corresponding shallow one.

Without those connections, the output is correct in category and blurry at the edges, because the boundary information was thrown away during downsampling and there is no way to invent it back. With them, boundaries are sharp.

Note that U-Net <em>concatenates</em> rather than adds, unlike ResNet. Concatenation preserves both sources separately and lets the following convolution decide how to combine them.

## Why it works on small datasets

U-Net was designed for biomedical images, where a dataset might contain thirty annotated examples. Several of its properties make that feasible.

- <strong>It is fully convolutional</strong>, with no dense layers, so it accepts any input size and has relatively few parameters.
- <strong>Heavy augmentation</strong> &mdash; particularly elastic deformation, which is realistic for tissue &mdash; multiplies the effective dataset.
- <strong>Every pixel is a training example.</strong> A single 512&times;512 image provides 262,144 labelled pixels, which is why so few images can be enough.
- <strong>Patch-based training</strong> lets large images be processed in tiles, with overlap to avoid edge artefacts.

The encoder is now usually replaced with a pretrained backbone &mdash; ResNet, EfficientNet &mdash; which improves results further. That variant is what most segmentation libraries give you by default.

## Why U-Net has to be a U

A segmentation network needs both a wide view and a precise one, and downsampling gives you the first at the cost of the second. U-Net's answer is the skip connection, and this measures exactly what it recovers -- by building the same decoder with and without it.

```python-run
import numpy as np

H = 32
# a 1-D "image": two regions with a boundary that is exactly at 17
EDGE = 21
truth = np.zeros(H)
truth[EDGE:] = 1.0
rng = np.random.default_rng(3)
sig = truth * 60 + 30 + rng.normal(0, 4, H)

print("A 1-D EXAMPLE, %d pixels, so every array fits on a line. the label" % H)
print("is 0 to the left of pixel %d and 1 from %d on:" % (EDGE, EDGE))
print("   input:  " + " ".join("%3.0f" % v for v in sig[:16]))
print("           " + " ".join("%3.0f" % v for v in sig[16:]))
print("   label:  " + "".join(str(int(v)) for v in truth))
print()

def pool(a):
    return a.reshape(-1, 2).mean(axis=1)

def up(a):
    return np.repeat(a, 2)

print("THE ENCODER: pool by 2, four times. each step doubles the receptive")
print("field and halves the resolution:")
enc = [sig]
for i in range(4):
    enc.append(pool(enc[-1]))
print("%-10s %10s %16s %20s" % ("level", "length", "receptive field",
                                "pixels per cell"))
for i, a in enumerate(enc):
    print("%-10d %10d %16d %20d" % (i, len(a), 2 ** i, 2 ** i))
print("   at the bottom, one cell summarises %d input pixels. that is the"
      % (2 ** 4))
print("   CONTEXT the network needs -- to decide whether this pixel is")
print("   road or pavement you have to see more than the pixel.")
print()

print("BUT LOOK WHAT HAPPENED TO THE BOUNDARY. the true edge is at %d:" % EDGE)
print("%-10s %10s %18s %18s"
      % ("level", "length", "edge cell index", "input pixels it covers"))
for i, a in enumerate(enc):
    d = np.abs(np.diff(a))
    k = int(np.argmax(d)) + 1
    lo, hi = k * (2 ** i), (k + 1) * (2 ** i) - 1
    print("%-10d %10d %18d %18s" % (i, len(a), k, "%d..%d" % (lo, hi)))
print("   at level 4 the boundary is known only to within %d pixels."
      % (2 ** 4))
print("   the fact that it sits at %d rather than anywhere else in that" % EDGE)
print("   16-pixel block has been averaged away. it is not attenuated or")
print("   hidden -- it is gone, and no decoder can invent it back.")
print()

print("A PLAIN DECODER: upsample four times from the bottom, nothing else.")
plain = enc[-1]
for _ in range(4):
    plain = up(plain)
print("   output: " + " ".join("%3.0f" % v for v in plain[:16]))
print("           " + " ".join("%3.0f" % v for v in plain[16:]))
pred_plain = (plain > plain.mean()).astype(int)
print("   thresholded: " + "".join(str(v) for v in pred_plain))
print("   label:       " + "".join(str(int(v)) for v in truth))
err_plain = int((pred_plain != truth).sum())
print("   %d pixel%s wrong, every one of them at the boundary."
      % (err_plain, "" if err_plain == 1 else "s"))
print("   the region labels are right; only the EDGE is wrong, and it is")
print("   wrong by as much as the coarsest level was uncertain.")
print()

print("A U-NET DECODER: at every upsampling step, CONCATENATE the encoder")
print("map from the matching level before continuing. here that is a")
print("simple average of the two, which is what a 1-filter conv over the")
print("concatenation would compute:")
u = enc[-1]
for i in range(4):
    u = up(u)
    skip = enc[len(enc) - 2 - i]
    u = (u + skip) / 2.0
    d = np.abs(np.diff(u))
    k = int(np.argmax(d)) + 1
    print("      after skip from level %d: length %2d, sharpest change at %d"
          % (len(enc) - 2 - i, len(u), k))
print("   output: " + " ".join("%3.0f" % v for v in u[:16]))
print("           " + " ".join("%3.0f" % v for v in u[16:]))
pred_u = (u > u.mean()).astype(int)
print("   thresholded: " + "".join(str(v) for v in pred_u))
print("   label:       " + "".join(str(int(v)) for v in truth))
err_u = int((pred_u != truth).sum())
print("   %d pixel%s wrong." % (err_u, "" if err_u == 1 else "s"))
print()

print("%-34s %14s %18s" % ("decoder", "pixels wrong", "boundary found at"))
for name, pred in (("upsample only", pred_plain), ("with skips", pred_u)):
    idx = np.where(np.diff(pred) != 0)[0]
    print("%-34s %14d %18s"
          % (name, int((pred != truth).sum()),
             str(idx[0] + 1) if len(idx) else "none"))
print("%-34s %14d %18d" % ("truth", 0, EDGE))
print()

print("WHY THE SKIP IS THE ONLY THING THAT COULD WORK. the two halves of")
print("the network hold different things, and neither is sufficient:")
print("%-22s %-24s %s" % ("", "encoder, deep", "encoder, shallow"))
for row in (("resolution", "coarse", "full"),
            ("receptive field", "large", "tiny"),
            ("knows WHAT", "yes", "no"),
            ("knows WHERE", "no", "yes")):
    print("%-22s %-24s %s" % row)
print("   a skip connection is how the decoder gets both at once: WHAT")
print("   from below, WHERE from the side. that is the entire idea, and")
print("   the U shape in the diagram is just what the wiring looks like")
print("   when you draw it.")
print()

print("ONE MORE THING THE SKIPS BUY, which is easy to miss: they are also")
print("a gradient path. the encoder's early layers are %d stages away from"
      % (2 * 4))
print("the loss through the U, and 1 step away through a skip. that is the")
print("same argument as a residual connection, and it is why U-Net trains")
print("on a few hundred images when it was published for biomedical data")
print("where a few hundred is all there is.")
print()
print("AND THE THING TO WATCH: the concatenation needs matching sizes.")
print("%-30s %14s %14s" % ("input length", "after 4 pools", "back up"))
for n in (32, 30, 36, 64):
    k = n
    ok = True
    for _ in range(4):
        if k % 2:
            ok = False
            break
        k //= 2
    print("%-30d %14s %14s"
          % (n, str(k) if ok else "not divisible",
             str(k * 16) if ok else "shapes mismatch"))
print("   an input that is not divisible by 2^depth comes back the wrong")
print("   size and the concatenation fails -- or worse, a library pads it")
print("   silently and every mask is off by a pixel. that is why U-Net")
print("   implementations insist on input sizes that are multiples of 32,")
print("   and why the original paper cropped the encoder features before")
print("   concatenating rather than padding them.")
```

## Guided tour

1. <strong>Read all three masks at 1 downsampling level.</strong> The no-skip reconstruction is already visibly blockier at the boundary than the ground truth circle.
2. <strong>Push depth to 3 levels.</strong> The no-skip mask's pixel accuracy drops further — each extra pooling level throws away more boundary detail that nearest-neighbour upsampling has no way to invent back.
3. <strong>Compare against the with-skip mask.</strong> It matches the ground truth exactly, at any depth — because this simplified version literally routes the original full-resolution mask across, rather than a pooled-and-corrupted feature map.

## What this simplification doesn't show

A real U-Net's skip connections carry learned <em>feature maps</em> across, not the raw ground-truth labels — its decoder still has to learn to fuse coarse semantic features with fine spatial ones, and that fusion is imperfect. A trained U-Net does not hit 100% pixel accuracy just because it has skip connections. What this toy demonstrates honestly is the underlying mechanism: recovering resolution that pooling destroyed by carrying it across directly, rather than trying to hallucinate it back from a coarse map alone — that mechanism is exactly why U-Net needs skip connections at all.

## What to remember

Downsampling for context and needing pixel-precise output are in direct tension — the same pooling that builds semantic understanding destroys the spatial detail a segmentation mask needs back. Skip connections resolve that tension not by improving the upsampling step, but by making it partly unnecessary: the fine detail rides across the encoder-decoder bridge instead of being reconstructed from a coarse map that no longer contains it.

## Losses for segmentation

Segmentation has a characteristic problem: class imbalance within the image. A tumour might occupy 1% of the pixels, and a model that predicts "background" everywhere scores 99% pixel accuracy.

The standard losses respond to this directly:

|Loss|Behaviour|
|---|---|
|Cross-entropy|Per-pixel classification; dominated by the majority class|
|Weighted cross-entropy|Rare classes weighted up|
|Dice loss|Optimises overlap directly; good for small foregrounds|
|Focal loss|Down-weights easy pixels, focuses on hard ones|
|Dice + cross-entropy|The common practical combination|

Dice loss is derived from the Dice coefficient, `2|A∩B| / (|A|+|B|)`, and because it is a ratio it is largely insensitive to how much background there is. Combining it with cross-entropy is the most common default in medical segmentation, because the two have complementary gradient behaviour.

For evaluation, <strong>mean IoU</strong> across classes is the standard metric, with the Dice coefficient (equivalent to F1 over pixels) more common in medical work. Pixel accuracy is reported occasionally and should be treated with the same suspicion as accuracy on any imbalanced problem.

## Alternatives and refinements

<strong>DeepLab</strong> uses dilated convolutions to widen the receptive field without downsampling at all, plus an atrous spatial pyramid that looks at several dilation rates in parallel. Strong on natural scenes.

<strong>FCN</strong> was the earlier fully-convolutional approach: take a classifier, replace the dense layers with convolutions, and upsample. Simpler and less precise at boundaries.

<strong>SegFormer and Mask2Former</strong> bring transformers to segmentation, with strong results at higher training cost.

<strong>Segment Anything (SAM)</strong> is a promptable foundation model that produces high-quality masks with no task-specific training, and is increasingly used to accelerate annotation rather than replace task-specific models.

For most applied projects, a U-Net with a pretrained encoder remains the pragmatic starting point, and `segmentation_models_pytorch` gives it in a few lines.

## Common mistakes

- <strong>Resizing masks with bilinear interpolation.</strong> This blends label values into meaningless intermediates &mdash; class 3.7. Always use nearest-neighbour for masks.
- <strong>Augmenting the image and not the mask,</strong> or applying different random parameters to each.
- <strong>Reporting pixel accuracy</strong> on an imbalanced problem.
- <strong>Ignoring the ignore label.</strong> Many datasets mark unlabelled pixels with a special value that must be excluded from the loss.
- <strong>Tiling without overlap,</strong> which produces visible seams at tile boundaries.
- <strong>Forgetting that the output needs an argmax</strong> across the channel dimension to become a label map.

## Questions people ask

<strong>How many annotated images do I need?</strong> Tens can work with heavy augmentation and a pretrained encoder; hundreds for reliable results on natural scenes.

<strong>Why concatenate instead of add in the skip connections?</strong> Concatenation keeps both feature sets intact and lets the next convolution learn how to weigh them. Addition assumes they are directly comparable.

<strong>What input size should I use?</strong> Any multiple of the total downsampling factor &mdash; typically 32. Mismatched sizes cause shape errors in the decoder.

<strong>How do I handle very large images?</strong> Tile with overlap and blend the predictions, or downsample if fine detail is not required.

<strong>Can U-Net do instance segmentation?</strong> Not directly &mdash; it does not separate touching objects of the same class. Mask R-CNN or a watershed post-processing step handles that.

<strong>Is U-Net outdated?</strong> No. It remains the default in medical imaging and is a strong, cheap baseline everywhere else.

## Recap in one screen

- Semantic segmentation assigns a class to every pixel; the output is the same size as the input.
- The tension is between semantic depth (needs downsampling) and spatial precision (needs resolution).
- U-Net downsamples, upsamples, and concatenates matching encoder features into the decoder &mdash; which is what keeps boundaries sharp.
- It works on tiny datasets because every pixel is a training example and augmentation goes a long way.
- Use Dice plus cross-entropy for imbalanced foregrounds, evaluate with mean IoU, and never interpolate masks bilinearly.

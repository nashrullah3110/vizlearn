title: Understanding Image Flattening
intro: Why and how we transform 2D grids of pixels into 1D lists for Neural Networks.

## The idea in brief

When you look at an image, you see a 2D grid of colors. However, standard Artificial Neural Networks (specifically <strong>Dense</strong> or <strong>Fully-Connected Layers</strong>) are structured to accept only a one-dimensional (1D) array or vector of numbers as input. Before a network can "look" at an image, the image must undergo <strong>Flattening</strong>.

## The Core Idea: Unrolling the Grid

Think of a digital image as a spreadsheet where each cell is a pixel holding a color value. "Flattening" is simply taking the first row of this spreadsheet, placing it down, taking the second row and appending it to the end of the first, and continuing until the whole grid forms a single, long line of numbers.

If the image is colored, it contains three channels: Red, Green, and Blue (RGB). The network needs separate input nodes for every color value of every pixel. The math for the total number of inputs is simple: <strong>Width &times; Height &times; Channels = Total Nodes.</strong>

## The Problem with Flattening

While flattening allows an MLP to process an image, it <strong>destroys spatial relationships</strong>. A pixel right above another pixel in 2D might be dozens of indices apart in the 1D array. Standard dense networks struggle to understand that these pixels were originally neighbors.

This exact problem led to the invention of Convolutional Neural Networks (CNNs), which process images in 2D first before flattening them at the very end!

## What to remember

- Dense neural network layers only accept 1D lists (vectors) as input.
- <strong>Flattening</strong> is the process of stringing rows of pixels together into a line.
- The size of the input layer is $W \times H \times C$ (Channels).
- High resolution images create massive input layers, making them computationally expensive.

Flattening is the bridge between raw image files and the mathematical matrix operations that power Artificial Intelligence.

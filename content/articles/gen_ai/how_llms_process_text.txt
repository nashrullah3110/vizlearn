title: The Journey from Characters to Prediction
intro: A language model never sees text. It sees numbers &mdash; and the transformation from your sentence to those numbers, and back to a prediction, is a fixed pipeline of stages. Stepping through them is the fastest way to demystify what "the model read my prompt" actually means.

## Stages 1–3: Text Becomes Integers

Tokenization splits the string into subword pieces, and each piece is looked up in the vocabulary to get an integer ID. That is the model's entire input: a list of integers. Nothing about the <em>meaning</em> of a word has entered yet &mdash; ID 4021 is no closer to ID 4022 than to ID 9. The IDs are arbitrary addresses, not measurements.

## Stage 4: Embeddings Give IDs Meaning

Each ID indexes into a giant lookup table, pulling out a learned vector of <span class="mono-font">d</span> numbers. <em>These vectors are where meaning lives.</em> Words used in similar contexts end up with similar vectors, and this table is trained along with everything else.

Notice the shape change: a list of <span class="mono-font">n</span> integers becomes an <span class="mono-font">n &times; d</span> matrix. Every stage from here on preserves that shape &mdash; the transformer transforms these vectors repeatedly without ever changing the grid size.

## Stage 5: Position Must Be Injected

Self-attention has no inherent sense of order &mdash; it sees a <em>set</em> of vectors, so "dog bites man" and "man bites dog" would be identical. Position is therefore added directly into the vectors, classically with sinusoids of geometrically increasing wavelength:

PE(pos, 2i) = sin(pos / 10000<sup>2i/d</sup>) &nbsp;&nbsp; PE(pos, 2i+1) = cos(pos / 10000<sup>2i/d</sup>)

The values in this lab are the genuine formula. Look along a row and you will see fast oscillation in the early dimensions and near-constant values in the later ones &mdash; that mix gives every position a unique fingerprint the model can decode.

## Stage 6: Attention Mixes the Tokens

Now every token looks at every other token. Each position produces a query and a key; their dot product, scaled by <span class="mono-font">&radic;d</span>, scores how relevant one token is to another, and a softmax over each row turns those scores into weights that sum to 1:

Attention(Q, K, V) = softmax(QK&#7488; / &radic;d) V

The heatmap in this stage is a real computation from the vectors above it. Each row shows where one token sent its attention. This is the step where a token stops being an isolated word and becomes a <em>contextual</em> representation.

## Stages 7–8: Depth, Then a Single Prediction

One attention block is repeated dozens of times, each with a feed-forward network, residual connections and normalisation. Early layers capture syntax; deeper layers capture semantics and task structure.

At the very end only the <strong>last position's</strong> vector is used for the next token. It is multiplied by the vocabulary matrix to produce one logit per possible token &mdash; and we are back to a distribution over words. The chosen token is appended to the input and the entire pipeline runs again, from stage 1, for every single word generated.

## Try it yourself

1. <strong>Walk from stage 1 to 8 with Next</strong> and keep an eye on the shape tag. Watch <span class="mono-font">n</span> integers become <span class="mono-font">n &times; d</span> and stay there until the final projection.
2. <strong>At stage 5, compare the two rows of "the".</strong> Identical embeddings, different positional vectors &mdash; which is the only reason the model can tell the two occurrences apart.
3. <strong>At stage 6, read the attention rows.</strong> Repeated words attend to each other strongly, because attention is driven by vector similarity.
4. <strong>Change the sentence to "man bites dog", then "dog bites man".</strong> Same tokens, different attention pattern &mdash; order genuinely changes the computation once positions are added.
5. <strong>Raise the model dimension.</strong> Every downstream matrix widens, which is the crudest possible illustration of why parameter counts explode with <span class="mono-font">d</span>.

## What to remember

Text in, integers, vectors, mixed vectors, logits, text out. The embeddings and attention weights in this lab are deterministic stand-ins for learned parameters, but the <em>operations</em> &mdash; sinusoidal positions, scaled dot-product attention, softmax &mdash; are the real ones. Understanding this pipeline makes context windows, tokenizer quirks and attention costs stop feeling arbitrary.

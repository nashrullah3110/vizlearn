title: Markov Chains
intro: A Markov chain models step-by-step movement between states when the next state depends on the current one.

## Transition probabilities

A chain has a state space and transition probabilities. With a row-vector convention, a transition matrix P has entries Pᵢⱼ = P(next state = j | current state = i); each row sums to 1. If πₜ is the row vector of state probabilities at time t, then πₜ₊₁ = πₜP.

For two states, sunny and rainy, a matrix such as [[0.8, 0.2], [0.4, 0.6]] says that a sunny day is followed by a sunny day with probability 0.8, while a rainy day is followed by a sunny day with probability 0.4. Starting from π₀ = [1, 0], after one step π₁ = [0.8, 0.2].

## The Markov assumption and long-run behavior

The Markov property says the next state is conditionally independent of earlier history once the current state is known. It is a modelling assumption; if relevant history is omitted, the model may be inadequate.

A stationary distribution satisfies π = πP. Some chains converge to one from many starting states, but convergence is not automatic: reducible or periodic chains can behave differently. See [conditional probability](conditional_probability.html) for transition probabilities and [matrix multiplication](matrix_multiplication.html) for repeated transitions.

## Multiply the transition matrix step by step

From the sunny starting state π₀=[1,0] and P=[[0.8,0.2],[0.4,0.6]], one step gives π₁=[0.8,0.2]. A second step is π₂=π₁P=[0.72,0.28]. Each row of P is a probability distribution for the next state given the current state, so rows sum to one. This uses a row-vector convention; with column vectors, the matrix and multiplication order are transposed. State the convention before calculating.

The Markov property says that once the present state is known, earlier states add no information about the next step. It does not say transitions are independent across time. A stationary distribution solves π=πP and describes a distribution unchanged by one transition. For this example, π=[2/3,1/3] is stationary. A finite chain may have a unique stationary distribution yet fail to converge from every start if it is periodic. If an omitted variable such as season affects transitions, include it in the state or accept that the simple chain may predict poorly. Markov models are useful for repeated state transitions, not for every time series.

## Try this above

Change one transition probability and keep each row normalised. Track how the state distribution evolves over several steps and whether it settles.

The long-run distribution can be found by solving π=πP along with the condition that probabilities sum to one. For the sunny/rainy matrix, solving gives π=[2/3,1/3]. Starting at that distribution leaves it unchanged at every step. A stationary distribution is not automatically the fraction of time observed in a short sequence; convergence requires additional conditions such as irreducibility and aperiodicity. Weather is only an illustration: real forecasting may need season, location, or trends represented in the state.

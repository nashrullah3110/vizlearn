title: Rank and Linear Independence
intro: Rank counts how many independent directions remain in a matrix's columns or rows.

## Independence means no redundancy

Vectors are linearly independent when the only combination that sums to zero uses all-zero coefficients. If one vector can be built from the others, it adds no new direction. The rank of a matrix is the dimension of its column space; it also equals the dimension of its row space.

For A = [[1, 2], [2, 4]], the second column is twice the first, so the columns are dependent and rank(A) = 1. The map can produce points on a line, but not fill the plane. For a square matrix, full rank is equivalent to a nonzero determinant; see [determinants](determinant.html).

## What rank reveals

Rank tells you the number of independent constraints or representable directions. A low-rank data matrix has redundancy that can sometimes be compressed; [singular value decomposition](singular_value_decomposition.html) reveals the dominant directions. Rank also predicts whether Ax = b has a unique solution, many solutions, or no solution, but the answer depends on consistency and the number of unknowns as well as rank.

Exact rank is sensitive to tiny floating-point noise. Numerical software therefore uses a tolerance when deciding which singular values count as zero. A nearly dependent matrix may be formally full-rank yet poorly conditioned.

## Try this above

Make one vector a multiple of another and watch the rank drop. Then perturb one component slightly; notice how exact dependence differs from near-dependence.

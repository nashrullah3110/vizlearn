title: Identity, Inverse and Transpose
intro: These three matrix operations describe doing nothing, undoing a map, and exchanging rows with columns.

## Identity leaves a vector unchanged

The identity matrix has ones on its diagonal and zeros elsewhere. Multiplying by it changes nothing: I x = x and AI = IA = A whenever the products are defined. It plays the role of 1 in matrix multiplication.

## Inverse undoes a transformation

For square A, its inverse A⁻¹ satisfies A⁻¹A = AA⁻¹ = I. It exists only when A is nonsingular. If A sends two distinct inputs to the same output, no operation can recover which input was used. Numerically, solving Ax = b with a factorisation is usually preferable to explicitly computing A⁻¹.

## Transpose swaps rows and columns

The transpose Aᵀ is formed by exchanging rows and columns. It reverses product order: (AB)ᵀ = BᵀAᵀ. For an orthogonal matrix Q, QᵀQ = I, so Qᵀ = Q⁻¹. This is why rotations and orthonormal coordinate changes are easy to undo. See [orthogonality](basis_span_and_orthogonality.html), [matrix multiplication](matrix_multiplication.html), and [projections](projections.html).

A useful check: for A = [[1, 2], [3, 4]], Aᵀ = [[1, 3], [2, 4]], while det(A) = −2, so this particular matrix has an inverse. A transpose always exists; an inverse does not.

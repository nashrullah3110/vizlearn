title: Type I and Type II Errors
intro: A decision threshold trades off false alarms against missed effects; power is the chance to detect a specified effect.

## The two error rates

A Type I error rejects a true null hypothesis; its long-run probability is the significance level α under the test procedure. A Type II error fails to reject a false null; its probability β depends on the alternative effect and study design. Power is 1−β.

<div class="vz-math-block" role="math" aria-label="power equals one minus beta, the probability of rejecting the null under a specified alternative">Power = 1 − β = P(reject H₀ | specified alternative)</div>

Lowering the decision threshold often reduces false positives while increasing missed effects, for a fixed design. Increasing sample size can improve power, but power also depends on variability, effect size, test direction, and α. There is no single power value independent of the alternative being considered.

## Choose the design before collecting data

Set α and choose a scientifically meaningful effect size in advance. A test with low power may miss a real effect; a statistically significant result can still be too small to matter. “Fail to reject” is not proof that the null is true. See [hypothesis testing and p-values](hypothesis_testing_and_p_values.html) and [confidence intervals](confidence_intervals.html).

## Read the decision table

| Reality | Reject the null | Do not reject the null |
| --- | --- | --- |
| Null is true | Type I error (false positive) | Correct non-rejection |
| A specified alternative is true | Correct detection (power) | Type II error (miss) |

For a screening test, a false alarm can trigger unnecessary follow-up, while a missed condition may delay care. Which error matters more depends on the costs in that setting. For a fixed design, making the rejection threshold stricter generally lowers the Type I error rate but can raise the Type II error rate. More data can improve power for a specified effect, but cannot remove bias or guarantee practical importance.

β depends on the alternative being considered: a test can have high power for a large effect and low power for a small one. A useful power calculation therefore specifies a meaningful effect, variability, α, and design before data collection. “Fail to reject” means the data did not cross the chosen threshold; it is not evidence that the null is exactly true. If the goal is to show that an effect is small enough to ignore, define an acceptable range and use an equivalence procedure.

## Try this above

Change the threshold and sample size while holding the alternative fixed. Compare the false-alarm region and probability of detecting the effect.

For example, in a quality-control test, α is the long-run false-rejection rate when production is actually on target. β is the miss rate for a particular shift from target. Reducing β by increasing sample size can make the test more sensitive, but may increase inspection cost. The appropriate balance depends on the consequences of false alarms and missed defects; there is no universally correct α. Pre-specify the effect size and decision costs so a post-hoc result does not redefine what counts as adequate power.

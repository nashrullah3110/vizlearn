## Overview

When we train a classification model, we need to provide it with labeled data. The way we represent these labels can have a significant impact on how the model learns. This lab explores two common approaches: <strong>Hard Labelling</strong> and <strong>Soft Labelling</strong>. By comparing them side-by-side, you can build a strong intuition for why representing uncertainty can lead to more robust and nuanced models.

## Defining the Labels

Imagine you're training a model to classify the sentiment of a tweet as 'Negative', 'Neutral', or 'Positive'. How you tell the model the "correct" answer for each tweet is where labelling strategy comes in.

<h4 class="font-bold" style="color: var(--text-main);">Hard Labelling (One-Hot Encoding)</h4>

This is the most common approach. You are 100% certain about the class. The correct class gets a value of 1, and all other classes get a 0. It's a "winner-takes-all" method. <br><strong>Example Vector:</strong> For a 'Positive' tweet, the hard label is <strong>[0, 0, 1]</strong>. This tells the model, "This tweet is positive, and nothing else."
<h4 class="font-bold" style="color: var(--text-main);">Soft Labelling (Probabilistic)</h4>

This method acknowledges that the world is messy and some data points are ambiguous. Instead of picking one class, you assign a probability distribution across all classes. <br><strong>Example Vector:</strong> For a tweet that is mostly positive but has a hint of neutrality, the soft label might be <strong>[0.1, 0.2, 0.7]</strong>. This tells the model, "I'm pretty sure this is positive, but there's a small chance it's neutral or even slightly negative."

## Things to try

Select different tweets from the list to see how these labelling strategies handle different scenarios.

1. <strong>The Clear-Cut Case:</strong> Select the second tweet: <em>"Absolutely stunning. Every detail is perfect. Highly recommend!"</em> This is unambiguously positive. Notice that the hard label <strong>[0, 0, 1]</strong> and the soft label <strong>[0.01, 0.04, 0.95]</strong> are very similar. In such clear cases, both methods convey almost the same information. The model is strongly encouraged to predict 'Positive'.
2. <strong>The Ambiguous Case:</strong> Now, select the first tweet: <em>"The design is gorgeous, but the software is a total nightmare to navigate."</em> This tweet contains both positive ('gorgeous design') and negative ('nightmare software') elements. <ul> <li>The <strong>Hard Label</strong> is forced to choose one winner. Here, it's classified as 'Negative' ([1, 0, 0]), completely ignoring the positive aspect. This forces the model to be overconfident and lose valuable information.</li> <li>The <strong>Soft Label</strong>, however, captures the nuance perfectly with a vector like <strong>[0.65, 0.1, 0.25]</strong>. It tells the model: "This is mostly negative, but there's a significant positive component too."</li> </ul>
3. <strong>The Neutral-Leaning Case:</strong> Select the last tweet: <em>"Shipping was late, but the box was packed really well."</em> Again, we see a mix of sentiments. The hard label might classify this as 'Neutral' ([0, 1, 0]), but the soft label <strong>[0.4, 0.45, 0.15]</strong> provides a much richer signal, indicating it leans neutral but has a strong negative element ('late shipping') and a minor positive one ('packed well').

## Why Use Soft Labelling?

While hard labelling is simpler, soft labelling offers several key advantages, a technique often referred to as <strong>Label Smoothing</strong>:

- <strong>Better Generalization:</strong> By preventing the model from becoming overconfident in its predictions for the training data, soft labelling helps it generalize better to new, unseen data. It acts as a form of regularization.
- <strong>Robustness to Noise:</strong> Real-world datasets often contain mislabeled examples. Soft labels can account for this uncertainty, making the training process more stable and less susceptible to noisy data.
- <strong>Capturing Inter-Class Relationships:</strong> Soft labels can implicitly teach the model about the relationships between classes. For example, it can learn that 'sarcastic' is closer to 'negative' than it is to 'positive'.
- <strong>Knowledge Distillation:</strong> Soft labels are the foundation of knowledge distillation, where the probabilistic outputs of a large, complex model are used as soft targets to train a smaller, more efficient model.

title: Regression Metrics
intro: Regression metrics summarize the differences between predicted and actual numeric values. They disagree because each weights error size and scale differently.

## Start with residuals

Regression metrics summarize how far numeric predictions are from observed values, but they weight errors differently. For residual <code>eᵢ = yᵢ − ŷᵢ</code>, MAE averages absolute errors while MSE squares them, so large misses count more.

## Four common metrics

For <code>n</code> observations, let <code>eᵢ = yᵢ − ŷᵢ</code>.

- **Mean absolute error (MAE)** = average of <code>|eᵢ|</code>. It is in the target’s units and treats each unit of error linearly.
- **Mean squared error (MSE)** = average of <code>eᵢ²</code>. It penalizes large errors more strongly and has squared target units.
- **Root mean squared error (RMSE)** = square root of MSE. It restores the target’s units while retaining the stronger penalty on large errors.
- **R-squared** = <code>R² = 1 − SSE/SST</code>, where SSE is squared prediction error and SST is variation around the target mean. It compares the model with predicting the mean; on test data it can be negative if the model performs worse than that baseline.

## Worked example: one large miss

Suppose three predictions have absolute errors 1, 1, and 4 units. MAE is <code>(1 + 1 + 4)/3 = 2</code>. MSE is <code>(1² + 1² + 4²)/3 = 6</code>, so RMSE is about 2.45. The 4-unit miss contributes 16 to the squared-error total, which explains why MSE and RMSE react more to large errors than MAE.

Use **MAE** when errors should count linearly and the result should be easy to explain. Use **RMSE** when large misses deserve extra weight. MSE is common as an optimization loss but its squared units are less intuitive. R-squared describes improvement over the mean baseline, not the typical error size; report it alongside MAE or RMSE when useful.

## A nearby metric: percentage error

Mean absolute percentage error (MAPE) divides absolute error by the actual value. It can be useful when relative error is meaningful, but it is undefined at zero and unstable near zero. It can also weight over- and under-prediction asymmetrically. Do not use it blindly for demand or other targets that can be zero.

## Common mistakes

- **Calling RMSE universally best:** the metric should match the costs of errors.
- **Comparing R-squared across unrelated datasets:** its value depends on target variance and data composition.
- **Ignoring target units:** MAE and RMSE are interpretable only with the target’s scale in mind.
- **Choosing a metric after seeing test results:** select the evaluation rule before final testing.

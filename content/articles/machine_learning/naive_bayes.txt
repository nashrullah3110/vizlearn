title: Naive Bayes
intro: Naive Bayes uses Bayes’ rule to compare class probabilities, with a simplifying assumption that features are conditionally independent given the class. It is fast and often useful for text, though its probability estimates can be overconfident.

## Bayes’ rule and conditional independence

Naive Bayes predicts a class by combining its prior probability with the likelihood of the observed features under that class. The “naive” assumption makes the calculation practical: given the class, the model treats each feature as independent of the others.

## Bayes’ rule and the independence assumption

For a class c and observed features x₁, …, xₚ:

<p><strong>P(c | x₁, …, xₚ) ∝ P(c) × P(x₁, …, xₚ | c)</strong></p>

Naive Bayes approximates the joint likelihood as a product:

<p><strong>P(c | x₁, …, xₚ) ∝ P(c) × ∏ᵢ P(xᵢ | c)</strong></p>

The features need not be independent in general; the assumption is conditional on the class. It is often false—for example, “New” and “York” are related words—but the approximation can still rank classes usefully. The class prior matters: common classes start with more probability before the features are considered.

## Work through a prediction

In the classic weather example, the observed features are Sunny, Cool and Strong wind. Without smoothing, the training counts give:

<p><strong>Score(Yes) = 9/14 × 2/9 × 3/9 × 3/9 = 1/63</strong></p>
<p><strong>Score(No) = 5/14 × 3/5 × 1/5 × 3/5 = 9/350</strong></p>

These are unnormalised scores: each is the class prior multiplied by the three class-conditional likelihoods. The No score is larger, so the model predicts No. Dividing each score by their sum would produce normalised probabilities. The visualiser uses Laplace smoothing to avoid zero likelihoods, so its displayed values differ from this unsmoothed hand calculation.

## What the assumption buys, and what it costs

The product turns a large joint-probability problem into separate per-feature counts. This makes training and prediction fast, even with many features and relatively few examples. It can work well for text classification, where word features are dependent but their counts still carry useful class information.

Naive Bayes variants match different feature types: Multinomial Naive Bayes is common for non-negative counts, Bernoulli Naive Bayes for binary indicators, and Gaussian Naive Bayes for continuous features modelled with class-specific normal distributions. Choosing the wrong variant or preprocessing can make the likelihoods inappropriate.

The independence approximation can produce probabilities that are too extreme, especially when correlated features repeat the same evidence. A strong class prediction is not proof that the probability is calibrated. If probability accuracy matters, evaluate a reliability curve and consider [calibration](probability_calibration.html). For a model that can learn feature interactions directly, compare with [logistic regression](logistic_regression.html).

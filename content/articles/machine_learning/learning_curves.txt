title: Learning Curves
intro: A learning curve plots training and validation performance as training-set size grows. The pattern can show whether a model is underfitting, overfitting, or still benefiting from more data.

## How to read the curves

Learning curves compare training and validation scores as the training sample grows. Their gap and direction can suggest underfitting, overfitting, or whether more representative data may help; they are diagnostic clues, not a guarantee that collecting data will improve a model.

## What the curves show

The horizontal axis is the number of training examples; the vertical axis is a score or error measured consistently on training and validation data. With an error metric, training error often rises as more examples are added, while validation error often falls. The gap and whether validation error is still improving are more useful than either curve alone.

| Pattern | Likely interpretation | Next question |
|---|---|---|
| Both errors high and close | The model may be underfitting | Can a more suitable model or feature set represent the pattern? |
| Training error low, validation error much higher | The model may be overfitting | Would regularisation or more representative data reduce the gap? |
| Both errors low and close, validation curve flat | Performance has largely plateaued | Would new features or a different model help more than more rows? |

These are diagnostic clues. Data leakage, distribution shift, small samples or an unsuitable metric can produce misleading curves.

## Compare model capacity in the visualiser

Use **Model capacity** to compare the synthetic training and validation curves. Low capacity illustrates a model that cannot fit the pattern; higher capacity can reduce training error while widening the validation gap. This visualiser varies model capacity, not the number of real training examples, so treat it as an illustration of the shapes rather than evidence that collecting data will improve a particular model.

For a real learning curve, repeatedly train on increasing subsets of the training data and score each fit on held-out validation data. Average over multiple splits when the dataset is small, and keep the validation procedure consistent across subset sizes.

## When more data may help

If validation error is still decreasing at the largest sample size, additional representative data may help. If both curves have flattened at high error, increasing model capacity or improving features is a more direct experiment. A large, stable gap suggests overfitting; more data can help, but so can regularisation and a simpler model.

Keep a final test set separate from model selection. Use cross-validation when comparing settings, and make sure the plotted score reflects the task—accuracy alone may hide poor performance on a rare class.
